# Demo Don Rinaldi

Landing conceptual para Don Rinaldi Barbería, desarrollada por Ross Digital Studio.

## Enfoque
- estética premium y editorial
- responsive mobile / tablet / desktop
- animaciones al hacer scroll
- servicios, trabajos, ubicación y contacto en un solo lugar
- CTA directo a WhatsApp
- imágenes de stock como material ilustrativo

## Datos usados
Se tomaron únicamente datos públicos visibles en el perfil de Instagram:
- Sarandí 591, Merlo
- WhatsApp 11 3568-5710
- Martes a jueves: 10:00 a 20:00
- Viernes y sábados: 10:00 a 21:00
- Servicios destacados visibles: cortes, color, permanente y productos

## Nota
La demo incluye `noindex,nofollow` y no pretende representar una web oficial del negocio.
